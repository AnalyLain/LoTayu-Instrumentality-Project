## 📖 项目简介
- LoTayu-Instrumentality-Project（即罗大佑补完计划），是一个专注于罗大佑音乐作品（尤其是其“特异歌曲”）系统化收录、深度解析与资源整理的开源静态Wiki项目。
- 本项目尤以罗大佑特异音乐作品为核心，聚焦其作品在两岸三地不同时代、不同地区的版本差异、文本改动、传播流变与时代隐喻，重点收录、拆解、分析具有特殊时代印记与地域差异化的「特异歌曲」，填补其在墙内某些作品因涉及敏感话题而无法自由流传的文化空白，构建一所供罗大佑歌曲爱好者以及刚刚入坑这个圈子，对罗大佑一些有特殊含义及时代背景的歌曲尚不理解的萌新们查阅资料的资料库。我们当然还会上传MV，MIDI等资源，方便我们的圈友们进行二创。
- 本项目最终形态为轻量化静态Wiki网站，无后端、无数据库、稳定可长期运维，兼具学术考据性、资源收藏性与科普传播性。


## 📝 项目特色
- 【两岸三地特异歌曲专项解析】
  - 众所周知，罗大佑的部分作品因地域审核、时代背景产生了不可避免的歌词删减、文本修改、曲目更名、版本替换。我们计划做对照考据，梳理台湾原版、香港改编版、大陆引进版的差异细节、改动原因与传播影响，还原作品完整创作原貌。

- 【全曲目系统化收录】
  - 我们计划按发行年代、专辑序列、题材分类、地域版本四大维度，规整罗大佑全部正式发行曲目，建立标准化曲目索引，形成完整作品谱系。

- 【多维乐曲资源整合】
  - 整理收录配套音乐资源，包含自制/开源MIDI工程、原版/修复版MV、乐谱扒谱资料、无损音频素材、曲目伴奏等，支持在线预览与合规下载，适配音乐学习、二次创作与赏析研究场景。

- 【轻量化静态Wiki架构】
  - 基于静态网页搭建，访问稳定、加载快速、无需服务器运维，支持全文检索、目录导航、分类归档，阅读体验媲美专业知识库（真的会如此吗🥲，豆包你别吹过头了）


## 📂 网站内容架构
项目站点采用模块化Wiki结构，整体规划如下：
1. 项目主页：项目宗旨、更新日志、整体规划、适配场景等说明
2. 全曲目索引库：按年代/专辑/题材/地区多维度检索曲目
3. **特异歌曲专题（核心板块）：版本对照、歌词分析、时代背景、创作动机、地域传播差异深度解析**
4. 音乐资源库：MIDI、MV、乐谱、伴奏、曲谱文档等资源归档与下载
5. 考据附录：参考资料、文献来源、专辑发行记录、媒体评述、创作访谈归档

## 😔 我们想对你说的话
首先，我们真心希望你的参与！
接下来是Q&A：
- “我们”是谁？
  - 我们是一群罗大佑歌曲爱好者，其中一位对罗大佑的歌曲（几乎全部）有极其深度的理解，并且极度痴迷于罗大佑的歌曲；而另一位则是一位好的AI使用者（也就是我，额啊）README的内容很多都是用AI生成的，不过这个板块的全部内容都是我们切实想对你说的。

- 我们为什么想做这个项目？
  - 我曾经看过一个梗，“两岸三地凑不出你罗哥的完整歌单...” 其实我们都是挺感性的人，我们只是很单纯的觉得，所谓歌曲，就是用来抒发愿慨，针砭时弊的。“ **子曰：小子何莫学夫《诗》？《诗》可以兴，可以观，可以群，可以怨。**”———《论语》；这里的“诗”其实就是古代的乐歌，而所谓“兴观群怨”，则分别是起兴意志、**观风俗之得失**、群相切磋、**讽刺时政**之意。

    罗大佑的歌无疑是兴观群怨的，甚至可以说，他那或嬉笑怒骂，或含沙射影，或激人奋进，或绵转悠长的演唱风格，也正是很多粉丝（包括我）能如此喜爱他的原因。在罗大佑出现之前，华语流行音乐（尤其是70-80年代初）大部分是风花雪月的小情歌、校园民谣或甜美温婉的流行曲（如邓丽君式的柔情）。而罗大佑之所以能被誉为“华语乐坛的教父”，正是因为他赋予了流行乐曲思想的深度。

    罗大佑第一次证明了，流行歌曲也能探讨社会转型、政治变幻、都市异化、环境破坏、教育体制以及人们在时代与政治游戏下的迷茫；他早期的黑衣、墨镜、卷发的“特异”形象，搭配咆哮式的摇滚唱腔，展现出一种对现实绝不妥协的批判姿态，满足了数代年轻人对“独立思考”和“叛逆精神”的寄托（我想这也是为什么我们会如此喜爱他吧）。而当他放下批判的利器时，他又能带给我们野百合也有春天一般的温柔。

    可是，不是所有人都希望听到他的歌，以至于他们也不希望我们听见，理解，传唱他的某些歌曲。

    《飞车》《首都》《皇后大道东》这“三大件”自不必说；《侏儒之歌》《京城夜》等也同样未能幸免于难。这些歌曲都是富有深意且具有极高的时代价值的，可是，有时候我也不知道该说什么，我也不想说什么了，“我想要说的前人们都说过了”。总之，在政治这操蛋的游戏下，很多人很难在高墙之内去理解这些歌曲的深意。油管（youtube）上自然有讲解这些歌曲的视频，可我们觉得很多视频分析得有点“不够格”，我们可以让它们变得更好。

    其实也算我们叛逆吧，反正我是看不惯某群“公仆”们嘴边挂着自己的光辉伟业却不许人民了解那些历史，以至于要把文艺作品抹杀的丑态，去你妈的。

    所以我们想做一个项目，叫做 LoTayu-Instrumentality-Project 罗大佑补完计划。项目名的灵感来源于《新世纪福音战士》（EVA）中的“人类补完计划”。我们希望这个项目能为那些尚未入坑或入坑没多久的“小罗”们讲解清楚，那些可能是你们入坑直接驱动的“特异歌曲”，它们被创作的时代背景是什么，它们的歌词有什么深意，以及自然而然的，它们为什么会被封禁。所以与此同时，你可能还能借此机会深入了解那段风云变幻的岁月，了解那段令人唏嘘却被当局不希望你了解历史。在我看来这也是文艺作品一个很重要的作用---立史为鉴，继往事，示世人，反了那《1984》般的乌托邦。

    当然，我们肯定不希望你仅仅是因为“特异歌曲”而入坑的，也不希望我们项目变成一个给键政小鬼摇旗呐喊的臭水沟。我们同样也会收录，分析，解读罗大佑的那些“不特异歌曲”。同时我们也会收集并上传有关歌曲的周边资源，比如各版本MV，乐曲MIDI，封面歌词等内容，还会收录一些趣事和名梗（今天拼了😎），最终构建一个服务于全体罗大佑粉丝的WIKI网站。

    我们不以盈利为目的并且愿意开源我们的项目，纯粹为爱发电。

    在此我们向华语乐坛的教父罗大佑先生致以最崇高的敬意，同时我们会注意版权问题，不会上传完整歌词等涉及版权的问题，而用嵌入外部链接或引用图片代替。

    所以就是这样了，希望能得到你们支持吧～所有热爱罗大佑的朋友们。

    爱你们喵。
