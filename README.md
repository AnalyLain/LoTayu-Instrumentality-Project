## 📖 项目简介
- LoTayu-Instrumentality-Project（即罗大佑补完计划），是一个专注于罗大佑音乐作品（尤其是其“特异歌曲”）系统化收录、深度解析与资源整理的开源静态Wiki项目。
- 本项目尤以罗大佑特异音乐作品为核心，聚焦其作品在两岸三地不同时代、不同地区的版本差异、文本改动、传播流变与时代隐喻，重点收录、拆解、分析具有特殊时代印记与地域差异化的「特异歌曲」，填补其在墙内某些作品因涉及敏感话题而无法自由流传的文化空白，构建一所供罗大佑歌曲爱好者以及刚刚入坑这个圈子，对罗大佑一些有特殊含义及时代背景的歌曲尚不理解的萌新们查阅资料的资料库。我们当然还会上传MV,MIDI等资源，方便我们的圈友们进行二创。
- 本项目最终形态为轻量化静态Wiki网站，无后端、无数据库、稳定可长期运维，兼具学术考据性、资源收藏性与科普传播性。


## 📝 项目特色
- 【两岸三地特异歌曲专项解析】
  - 众所周知，罗大佑的部分作品因地域审核、时代背景产生了不可避免的歌词删减、文本修改、曲目更名、版本替换。我们计划做对照考据，梳理台湾原版、香港改编版、大陆引进版的差异细节、改动原因与传播影响，还原作品完整创作原貌。

- 【全曲目系统化收录】
  - 我们计划按发行年代、专辑序列、题材分类、地域版本四大维度，规整罗大佑全部正式发行曲目，建立标准化曲目索引，形成完整作品谱系。

- 【多维乐曲资源整合】
  - 整理收录配套音乐资源，包含自制/开源MIDI工程、原版/修复版MV、乐谱扒谱资料、无损音频素材、曲目伴奏等，支持在线预览与合规下载，适配音乐学习、二次创作与赏析研究场景。

- 【轻量化静态Wiki架构】
  - 基于静态网页搭建，访问稳定、加载快速、无需服务器运维，支持全文检索、目录导航、分类归档，阅读体验媲美专业知识库（真的会如此吗🥲，豆包你别吹过头了）


## 📂 网站内容架构
项目站点采用模块化Wiki结构，整体规划如下：
1. 项目主页：项目宗旨、更新日志、整体规划、适配场景等说明
2. 全曲目索引库：按年代/专辑/题材/地区多维度检索曲目
3. **特异歌曲专题（核心板块）：版本对照、歌词分析、时代背景、创作动机、地域传播差异深度解析**
4. 音乐资源库：MIDI、MV、乐谱、伴奏、曲谱文档等资源归档与下载
5. 考据附录：参考资料、文献来源、专辑发行记录、媒体评述、创作访谈归档
