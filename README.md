# “ 今天拼了！！！”
>本项目为共建项目，项目目前处于建站阶段。

## 📖 项目简介
LoTayu-Instrumentality-Project（即罗大佑补完计划），是一个专注于罗大佑音乐作品（尤其是其“特异歌曲”）系统化收录、深度解析与资源整理的开源静态Wiki项目。
本项目以罗大佑全维度音乐体系为核心，聚焦其作品在两岸三地不同时代、不同地区的版本差异、文本改动、传播流变与时代隐喻，重点收录、拆解、分析具有特殊时代印记与地域差异化的「特异歌曲」，填补大众听歌视角下的作品细节空白，构建一套完整、严谨、可查阅、可溯源的罗大佑音乐考据资料库。
项目最终形态为轻量化静态Wiki网站，无后端、无数据库、稳定可长期运维，兼具学术考据性、资源收藏性与科普传播性。
